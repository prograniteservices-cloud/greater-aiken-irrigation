# Greater Aiken Irrigation

A comprehensive service platform for irrigation and landscaping in the Aiken, SC area.

## Tech Stack
- **Framework**: Next.js 16.1.4
- **Backend**: Supabase
- **Styling**: Tailwind CSS 3, Framer Motion
- **Language**: TypeScript
- **UI Components**: Lucide React

## Key Features
- **Lead Capture & CRM**: Integrated lead collection and management via Supabase.
- **Service Management**: Dynamic landing pages for specialized irrigation services.
- **Modern UI**: Smooth Framer Motion transitions and responsive design.
- **Email Lead Setup**: Pre-configured workflows for email lead notifications.

## Status
- Core app structure and Supabase integration complete.
- Lead management workflows and email notification setup in progress.
